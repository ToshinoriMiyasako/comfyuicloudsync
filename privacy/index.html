DATA & PRIVACY

プライバシーポリシー

制定・最終更新：2026年10月3日

本ポリシーは、個人用同期ツールComfyUICloudSyncによるデータの取り扱いを説明します。

1. 対象となるデータ

同期対象は、利用者のローカルPCに保存された生成画像と、プロンプト、ネガティブプロンプト、シード、モデル・LoRA、生成設定、生成日時、ファイル名、保存場所などの生成履歴です。

Google APIを通じて、アプリが作成またはアクセスを許可されたDriveファイルの識別情報と、指定されたスプレッドシートの履歴・管理情報を読み取ります。スプレッドシートの採否・理由・メモ欄は、利用者が記入した評価を保持するために参照される場合があります。

2. 利用目的とGoogle API権限

データは、画像保存、生成履歴の記録、重複防止、同期結果の確認、失敗時の再試行に使用します。

  • drive.file：アプリが作成またはアクセスを許可されたDriveファイルを扱うために使用します。
  • spreadsheets：指定したスプレッドシートの履歴の読み書きに使用します。この権限自体はスプレッドシート全体へのアクセスを許可しますが、同期処理は設定された保存先を対象にします。

Google APIから取得した情報の利用および他のアプリへの移転は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

3. 保存場所と認証情報

生成画像と履歴は利用者のローカルPC、および利用者が認証したGoogleアカウントのDrive・スプレッドシートに保存されます。生成履歴には、管理のために元画像のローカルパスが含まれる場合があります。

同期待ち画像と処理状態はローカルPCに一時保存されます。同期確認後に待機用の画像コピーを削除し、重複防止用の処理記録はローカルに保持します。保存済み画像や履歴には自動の保存期限を設けていません。

OAuthクライアント設定と認証トークンはローカルPCに保存され、Google APIへの認証に使用されます。本ツールはGoogleアカウントのパスワードを取得・保存しません。Google APIとの通信にはHTTPSを使用します。

4. 共有・第三者提供

本ツールは、同期先として指定されたGoogleのサービスへデータを送信します。Googleの各サービスによる取り扱いには、Googleの規約とプライバシーポリシーが適用されます。

本ツールはDrive画像の一般公開設定を自動で有効にせず、利用者が設定したDrive・スプレッドシートの共有範囲を拡大しません。保存先が共有済みの場合は、その共有先のユーザーがデータを閲覧できることがあります。

本ツールの運営者が、同期データを広告配信、販売、第三者向け分析、汎用AIモデルの学習のために提供することはありません。

5. 接続の解除とデータ削除

同期を停止し、Googleアカウントの接続管理から本アプリへのアクセスを解除できます。ローカルの認証トークンも利用者が削除できます。

接続解除だけでは保存済みの画像や生成履歴は削除されません。利用者がDrive画像、スプレッドシートの行やファイル、ローカル画像、同期待ちデータ、処理記録をそれぞれ削除してください。同期を再開する場合、ローカルに残っている対象画像が再送信されることがあります。

6. この説明サイトとお問い合わせ

この説明サイトには画像アップロード、Google認証、生成履歴の閲覧、独自のアクセス解析機能はありません。サイトの配信基盤が、配信や保護のためにアクセス情報を処理する場合があります。

個人用ツールの設定やデータに関する問い合わせ先は、Google認証画面に設定されたユーザーサポートメールです。データの取り扱いが変更された場合は、本ページを更新します。
